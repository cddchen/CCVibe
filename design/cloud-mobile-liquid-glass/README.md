# Cloud Mobile Liquid Glass

可编辑的 Cloud 移动端高保真设计稿，包含首页和会话页。直接打开 `index.html` 即可查看，不依赖构建工具或外部资源。

## 编辑方式

- 使用顶部“编辑文案”直接修改画板中的文字。
- 使用右侧材质控制器调整玻璃透明度、背景模糊、饱和度、高光和阴影。
- 使用“首页 / 会话页 / 双画板”切换视图。
- 使用“复制令牌”将当前液态玻璃 CSS 变量复制到剪贴板。
- 页面内容、尺寸和组件样式分别位于 `index.html`、`styles.css` 和 `app.js`。

## 设计范围

- 首页：Cloud 品牌、新对话、工作目录、远程主机、模型选择、会话列表。
- 会话页：消息流、思考摘要、工具调用、权限确认、模型选择与输入区。
- iOS 和 Android 共用信息架构，系统层只需替换状态栏、安全区和原生交互实现。
