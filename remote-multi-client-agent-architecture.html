远程 Claude Agent · 多客户端一致性架构

Claude SDK 持久化 transcript · Agent Host 投影状态 · Snapshot + Action Replay · 多客户端 URI 订阅

客户端同步协议

  • • JSON-RPC 2.0 over WSS；按 root/session/chat URI 订阅
  • • 初次订阅拿 Snapshot，后续只收可归约的 typed actions
  • • 重连携带 clientId + lastSeenServerSeq + subscriptions
  • • replay 窗口失效时，以 fresh snapshot 替换本地 confirmed state

Claude SDK 边界

  • • SDK 的 list/info/messages 是原生 session 历史事实源
  • • 每个 exact chat 显式绑定一个 sdkSessionId，不依赖连接 ID
  • • 同一 SDK session 的 send/control 经 sequencer；不同 session 并行
  • • idle 可释放 WarmQuery，下次通过 resume 冷恢复 transcript

模型、审批与下线

  • • model + effort 作为一个 ModelSelection 原子设置并写 overlay
  • • 同 transport 热更新在下一请求生效；需要时下次 send rebind
  • • 审批状态广播给所有 eligible 客户端；first-valid-wins
  • • 客户端下线不停止 active turn；回来先 replay，失败则 snapshot
